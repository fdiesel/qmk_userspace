# fdiesel Halcyon Kyria's Keymap

Changes can compiled in the ci by pushing to the remote or locally with QMK MSYS.

1. Install and start QMK MSYS

[qmk/qmk_distro_msys](https://github.com/qmk/qmk_distro_msys/releases/tag/1.12.0)

2. Install qmk firmware

```bash
qmk setup
```

3. Select the user space

```bash
cd <your qmk_userspace dir>
```

4. Compile

```bash
qmk userspace-compile
```
